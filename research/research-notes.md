# Research Notes: AI Coding Agents

## Introduction
AI coding agents are artificial intelligence tools that help developers write, understand, test and improve computer programs.

## Examples
- GitHub Copilot
- Microsoft AI coding tools
- Other AI programming assistants

## Benefits
1. Saves developers time.
2. Helps find programming errors.
3. Explains complicated code.
4. Supports software testing.

## Challenges
1. AI can produce incorrect code.
2. Generated code may have security problems.
3. Developers must check the results.
4. Overdependence may affect programming skills.

## Conclusion
AI coding agents are changing software development. However, developers still need programming knowledge and problem-solving skills.
